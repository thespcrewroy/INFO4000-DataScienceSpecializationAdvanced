<p align="center">
  <b>INFO 4000 focuses on advanced applications of artificial intelligence, machine learning, and deep learning. The course covers API development, data integration, SQL databases, transfer learning with pretrained models, AI agents and workflow automation, audio analytics, MQTT-based communication, and reinforcement learning. Students gain hands-on experience developing applications using frameworks such as PyTorch and Hugging Face with an emphasis on practical implementation and independent projects.<sub></b>

## Materials
* Bash CLI
* `uv` Package Manager
* Python 3.12+
* Jupyter Lab
* VSCode
* Virtual Environments (`.venv`, `.toml`, `uv_lock`)
* Packages: `numpy`

## Topics
|  Week  |                                  Topic                                  |
|--------|-------------------------------------------------------------------------|
| `wk01` | `Python Environments and Streamlit`                                     |
| `wk02` | `Data Integration, APIs, and Transfer Learning`                         |
| `wk03` | `Pretrained Models and Fine-Tuning`                                     |
| `wk04` | `Vision Transformers, LLMs, and Retrieval-Augmented Generation (RAG)`   |
| `wk05` | `MQTT Communication and Reinforcement Learning`                         |
| `wk06` | `Gymnasium and Deep Q-Learning (DQN)`                                   |
| `wk07` | `Audio Analytics and Physics-Informed Neural Networks (PINNs)`          |
| `wk08` | `Physics-Informed Models and Digital Twins`                             |
| `wk09` | `Anomaly Detection, Digital Twins, and AI Agents`                       |
| `wk10` | `Agentic AI, Deep Reinforcement Learning, and PINN Control`             |
| `wk11` | `Model Context Protocol (MCP) and Tool-Using AI Agents`                 |
| `wk12` | `MCP Servers, Clients, and Agentic Application Development`             |
